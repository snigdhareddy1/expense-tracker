Expense Tracker

About the Project
The Expense Tracker is a simple Python project that helps users record and manage their daily expenses.

Features
- Add expenses with date, category and amount.
- Stores expenses as dictionaries.
- Validates dates and amounts before saving.
- Calculates total spending by category.
- Saves expenses into a CSV file.

 Technologies Used
- Python
- CSV module
- Datetime module

 How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run `expense_tracker.py`.

 Output
The program generates an `expenses.csv` file that can be opened in Excel or Google Sheets.
